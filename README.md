# Nawa Paint — نواة

نسخة أولية لبرنامج رسم بواجهة بسيطة مستوحاة من مساحة العمل في Procreate، ومحرك فرش مستقل يدعم ضغط القلم وتثبيت الخط. لا تستخدم هذه النسخة محرك SAI أو كود Procreate، ولا تدّعي تقديم نفس جودة الفرش.

## نسخة Windows

الحزمة الناتجة: `dist/NawaPaint-win32-x64/`. فكّ ضغط الحزمة بالكامل ثم افتح `NawaPaint.exe`. يجب إبقاء ملف التشغيل مع ملفات الحزمة؛ نقل exe وحده لا يكفي. النسخة محمولة ولا تحتاج تثبيت Node على جهاز المستخدم. الحزمة غير موقّعة رقمياً. جرى بناء الحزمة من Linux؛ تشغيلها على Windows وتجربتها بقلم رسم ما زال يحتاج جهاز Windows.

## iPad وApple Pencil

مجلد `app/` هو نسخة ويب متجاوبة. لفتحها على iPad، استضف محتواه على موقع HTTPS وافتحه في Safari، ثم اختر «إضافة إلى الشاشة الرئيسية». لا توجد خدمة سحابية أو رفع صور في التطبيق؛ الصور والمشاريع تُصدَّر إلى ملفات تختار حفظها. يسمح عامل الخدمة باستخدام الواجهة دون اتصال بعد تحميلها لأول مرة عبر HTTPS. لا يحتفظ التطبيق تلقائياً بمشروع الرسم عند إغلاقه، لذلك احفظ ملف `.nawa` قبل الخروج.

يدعم الكود Pointer Events وضغط القلم حين يوفّر المتصفح هذه البيانات. خيار «الرسم بالقلم فقط» يمنع أحداث لمس الأصابع من الرسم؛ ليس نظام رفض راحة يد أصلياً. تجربة Apple Pencil على iPad الحقيقي لم تُجرَ. هذه نسخة ويب، وليست تطبيق iPad أصلياً أو ملف IPA. التطبيق الأصلي يحتاج Xcode على Mac وتوقيع Apple واختبارات على الجهاز.

## الميزات الحالية

- لوحة ثابتة 1600 × 1000، فرش حبر ورصاص وهوائية وألوان شفافة، وممحاة.
- تغيير الحجم والشفافية والتثبيت، وربط حجم الفرشاة بضغط القلم.
- حتى 12 طبقة مع إخفاء وترتيب وشفافية ودمج عادي/Multiply/Screen.
- تراجع وإعادة بحد أقصى 15 خطوة، وحد ذاكرة تقريبي 96 MiB لسجل الصور. يقل عدد الخطوات مع زيادة الطبقات.
- حفظ وفتح مشاريع `.nawa` مع طبقاتها، وتصدير PNG بخلفية بيضاء.
- تكبير وتصغير وملاءمة اللوحة. لا توجد إيماءات تدوير أو تحريك بأصبعين في هذه المرحلة.

الفرش الشفافة تعتمد تراكم اللون، وليست محاكاة مزج ألوان رطبة. لا يوجد استيراد PSD أو فرش Procreate/SAI، أو تحديد وتحويل، أو مزج ألوان متقدم. تطوير الإحساس بالفرش وزمن الاستجابة ورفض راحة اليد يحتاج قياسات وتجارب على الأجهزة المستهدفة.

## التطوير

متطلبات: Node.js 24 وnpm، ومتصفح Chromium للاختبارات. استخدم checkout الحالي؛ كل مهمة سحابية معزولة ولا تحتاج Git worktree إضافياً.

```sh
cd /workspace/a7med417
npm ci --cache /workspace/.npm-cache
npm run dev
```

خادم التطوير يستمع على loopback والمنفذ 4173 للتحقق المحلي داخل البيئة. لا يمكن للـiPad الوصول إلى loopback الخاص بهذه البيئة. تطبيق سطح المكتب على جهاز مناسب يبدأ بـ`npm start`.

تم تنزيل Electron والتحقق منه باستخدام وكيل HTTPS الموجود. التشغيل المكتبي داخل هذه الآلة السحابية غير متاح بسبب إعداد sandbox الخاص بـLinux؛ لم يتم تعطيل sandbox. مسار التطوير الذي تم التحقق منه هنا هو المتصفح. عند تنزيل Electron أو بناء حزمة Windows داخل البيئة، اضبط `XDG_CACHE_HOME=/workspace/.cache` و`electron_config_cache=/workspace/.cache/electron` و`ELECTRON_GET_USE_PROXY=1` لاستخدام مسار cache قابل للكتابة والوكيل الموجود.

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
npm run package:win
```

يمكن تعديل `CHROMIUM_PATH` إلى مسار Chromium على جهازك. اختبارات المتصفح تتحقق من تغيّر البكسلات، والتراجع والإعادة والممحاة والطبقات، وضغط قلم مصطنع، وحفظ وفتح المشروع وتوقيع PNG ورفض المشاريع غير الصالحة. هذه الاختبارات لا تتحقق من تجربة أجهزة القلم الفعلية أو من تشغيل exe على Windows.

إذا غيّرت ملفات الواجهة، حدّث اسم cache في `app/sw.js` عند نشر نسخة ويب جديدة. لا يتم النشر أو الرفع إلى GitHub تلقائياً.
